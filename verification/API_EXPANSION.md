# Office.js API expansion: Windows golden handoff

This batch adds **49 methods**, each exercised by an `officejs/api_*` case.
The cases and expected local results run in Mog's `api_expansion` integration test.
**Excel goldens have not been generated.** Local checks establish Mog behavior;
Excel parity remains to be checked on Windows with licensed desktop Excel.

From the calipers repository root on Windows:

```powershell
go build -o calipers.exe ./cmd/calipers
.\calipers.exe excel-run-pass verification\cases\officejs
```

The pass skips existing goldens and generates pending scripted cases. Commit the
new `golden.xlsx` and `golden.xlsx.meta.json` files in calipers, then update Mog's
submodule pointer before running the engine comparison.

Fixtures are generated by `go run ./scripts/gen-officejs-cases`. Their source is
`scripts/gen-officejs-cases/specs_expansion.go`. Every query records its result in
worksheet cells. Filter cases record hidden rows; comment cases remove their
threads after recording results to avoid account-specific authors and timestamps.

## Contracts to compare with Excel

The fixtures cover table criteria and row visibility; conditional-format
lookup, deletion and ranges; comment/reply lookup, deletion and locations;
used ranges with and without formatting; search/replace results; freeze-pane
locations; and indentation. Mog also tests cross-sync identity, null-object
errors, wildcard escaping, search wraparound, sparse worksheet bounds,
comment movement after row insertion, and partial conditional-format clearing.

`Filter.applyIconFilter` remains unsupported by the engine and is not counted.
The added filter convenience methods share the existing AutoFilter criteria
parser, including its existing limits on rich/date values and dynamic criteria.
Comment creation in these fixtures uses plain text.

API contracts: [Microsoft Excel JavaScript reference](https://learn.microsoft.com/javascript/api/excel?view=excel-js-preview).
